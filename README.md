Entry for [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) on make.fun.

`main.py` writes exactly one emoji to `/output/entry.txt`:

> 😄

A grinning face with smiling eyes: a big, genuine smile that reads as warm at first
glance, with no context needed. It is not the first default smiley, it carries no hug or
flirtation that would read oddly from a stranger, and it is the same in any age or
background. One character, four bytes, no trailing newline.

Run it with Python 3.13 (no network, no dependencies):

```sh
python3 main.py
```
